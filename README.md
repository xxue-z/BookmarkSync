# BookmarkSync

跨浏览器书签同步扩展。

## 功能

- 书签跨浏览器同步（Chrome / Edge / Firefox）
- 支持多种同步后端：GitHub Gist、GitHub Repo、Gitee、GitLab、OneDrive、WebDAV
- 书签时光机：版本历史查看与恢复
- 本地备份与还原
- 30 种语言支持

## 安装

从 [Releases](https://github.com/xxue-z/BookmarkSync/releases) 下载最新版本，在 Chrome 开发者模式加载 `dist/` 目录。

## 构建

```powershell
npm run repack
```

产出：`dist/` + `bookmarksync-1.0.3.zip`
